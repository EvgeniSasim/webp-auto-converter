# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.3.x   | Yes       |
| 1.2.x   | Yes       |
| 1.1.x   | Yes       |
| < 1.1   | Best effort |

Security fixes are released for the current stable branch. Upgrade via WordPress admin or the latest [GitHub Release](https://github.com/EvgeniSasim/webp-auto-converter/releases).

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues.**

1. Use [GitHub Security Advisories](https://github.com/EvgeniSasim/webp-auto-converter/security/advisories/new) (preferred), or
2. Contact the maintainer via the email linked on their [WordPress.org profile](https://profiles.wordpress.org/evgeniisasim/).

Include:

- Description of the vulnerability and impact
- Steps to reproduce
- Affected plugin version
- WordPress / PHP version if relevant

We aim to acknowledge reports within **5 business days** and provide a fix or mitigation plan within **30 days** for confirmed issues.

## Scope

In scope:

- Plugin code in `webp-auto-converter/`
- Admin settings, batch AJAX endpoint, file conversion and deletion

Out of scope:

- Vulnerabilities in WordPress core, themes, or other plugins
- Server misconfiguration (file permissions, exposed credentials)

## Safe harbour

We appreciate responsible disclosure and will credit reporters in the release notes when agreed.
